# Students-Performance-Classification
This project predicts whether a student will Pass or Fail based on academic and demographic features using Artificial Neural Networks (MLPClassifier).   The main goal is to analyze how different activation functions and network architectures affect model performance and overfitting.

---

Features
- Binary classification: Pass (1) / Fail (0)
- Data preprocessing and feature engineering
- Comparison between tanh and logistic (sigmoid) activation functions
- Multiple neural network architectures
- Overfitting analysis (Train vs Test accuracy)
- Model selection based on test accuracy
- Visual performance evaluation

---

Models Used
- Multi-Layer Perceptron (MLP)
- Architectures:
  - (4, 4)
  - (10, 8, 4)
- Activation Functions:
  - tanh
  - logistic

---

Evaluation Metrics
- Accuracy (Train & Test)
- Confusion Matrix
- Classification Report
- Accuracy Comparison Bar Chart
- Overfitting Analysis Plot

---

Technologies & Libraries
- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn

---

Results
- Best model selected based on highest test accuracy
- Visual comparison shows the impact of model complexity and activation functions on performance
- Overfitting analyzed using Train vs Test accuracy plots
